## 0. 先认识 6 个最基本的东西

学代码不用先学完语法。下面 6 个，认识它们就能读懂大半。

| 写法 | 意思 | 生活类比 |
|---|---|---|
| `import` | 去工具箱拿工具 | 从抽屉里拿剪刀 |
| `name = 值` | 起个名字，把值存进去 | 贴标签 |
| `[...]` | 列表，一排东西 | 一个收纳盒 |
| `def 名字():` | 定义一段操作 | 给一套动作起名 |
| 缩进（4 个空格） | 表示"属于上一行" | 目录的层级 |
| `#` 开头 | 注释，写给人看 | 便签纸 |

记住一句：**代码是给电脑看的，注释是给人看的。**

## 3. 第 25–30 行：切块优先顺序

```python
SEPARATORS = ["\n\n", "\n", "。", "！", "？", "；", "，", " ", ""]
_MIN_BODY_BUDGET = 50
```

- `SEPARATORS` 是一个列表。
- 列表里放的是一串"分隔符"。
- `"\n\n"` 表示连续两个换行。也就是段落之间那个空行。
- `"\n"` 表示一个换行。
- `"。"` `"！"` `"？"` `"；"` `"，"` 是中文标点。
- `" "` 是一个空格。
- `""` 是空字符串。它放最后。
- 空字符串的意思是：实在切不开，就一个字一个字切。
- 顺序非常重要。越靠前，越像"一句话说完的地方"。
- 切块工具会从左往右试。先试空行，不行再试句号，一路退到最后。
- `_MIN_BODY_BUDGET = 50`：正文至少留 50 个字。
- 名字前面的下划线 `_` 表示"这是内部用的，外面别碰"。
- 为什么至少 50：前缀会占字数，占太多的话正文就剩几个字，没有信息量。

## 4. 第 33–41 行：Chunk 这个盒子

```python
@dataclass
class Chunk:
    text: str
    raw_text: str
    doc_name: str
    page_no: int
    chunk_index: int
    context_prefix: str = ""
```

- `class` 表示"定义一个类型"。
- 这个类型叫 `Chunk`，中文就是"块"。
- 它像一个表格模板，规定了"一块要有哪些字段"。
- `@dataclass` 是装饰器，写在 class 上面。
- 它的作用是自动生成初始化代码，省事。
- `text: str`：字段名叫 `text`，类型是字符串。
- `str` 就是文字。
- `int` 就是整数。
- `page_no: int`：页码是数字。
- `context_prefix: str = ""`：等号后面是默认值。
- 默认值的意义：创建时不传，就用这个值。
- 为什么 `text` 和 `raw_text` 要分开？
- `text` 带前缀，是送去算向量的版本。
- `raw_text` 不带前缀，是给人看的版本。
- 分开放，调试和展示时不会看到重复的标题。

## 5. 第 43–50 行：把盒子变成字典

```python
    def to_metadata(self) -> dict:

```

- `def` 表示定义函数。

- `return` 表示把结果交出去。
- `{...}` 是字典，也就是一堆"键: 值"。
- 为什么要有这个方法？
- 因为向量库只能存简单数据。
- 不能直接丢一个 Chunk 对象进去。
- 必须先转成字典。

## 7. 第 58–67 行：造一个切块工具

```python
@lru_cache(maxsize=8)
def _make_splitter(chunk_size: int, chunk_overlap: int):
    return RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_overlap,
        separators=SEPARATORS,
        keep_separator=True,
        length_function=len,
    )
```

- 这个函数输入两个数字，输出一个切块工具。
- `@lru_cache(maxsize=8)` 表示记住最近 8 种参数组合。
- 好处：同样的参数第二次调用，直接拿现成的。
- `chunk_size` 是每块最大字数。
- `chunk_overlap` 是相邻块重叠多少字。
- `separators=SEPARATORS` 用上面那张优先顺序表。
- `keep_separator=True` 表示切的时候把句号留下。
- 不留下的后果：句子末尾的句号会丢。
- `length_function=len` 表示用 `len()` 数字符个数。
- 中文一个字算一个字符，够用。

## 8. 第 70–79 行：判断这一行是不是标题

```python
def _parse_heading(line: str):
    stripped = line.lstrip()
    if not stripped.startswith("#"):
        return None
    level = len(stripped) - len(stripped.lstrip("#"))
    title = stripped[level:].strip()
    if not title or level > 6:
        return None
    return level, title
```

- 输入一行字。
- `.lstrip()` 去掉左边的空格。
- `.startswith("#")` 判断是不是以 `#` 开头。
- 不是就 `return None`，表示"这不是标题"。
- `len(...) - len(...)` 这个减法在数前面有几个 `#`。
- 几个 `#` 就是几级标题。
- `stripped[level:]` 是从第 level 个字符开始截取。
- 效果就是去掉前面的 `#`。
- `.strip()` 再去掉两边空格。
- `if not title or level > 6` 表示标题是空的，或者层级太大。
- 这两种情况都不认。
- 最后 `return level, title` 一次返回两个值。
- 这种写法叫元组。

## 9. 第 82–107 行：按标题把一页切成若干段

```python
def _split_markdown_segments(text, inherited_path):
    segments = []
    path = list(inherited_path)
    buffer = []

    def flush():
        body = "\n".join(buffer).strip()
        if body:
            segments.append((list(path), body))
        buffer.clear()

    for line in text.splitlines():
        heading = _parse_heading(line)
        if heading:
            flush()
            level, title = heading
            path = path[: level - 1] + [title]
            continue
        buffer.append(line)
    flush()
    return segments, path
```

- 输入：一页文字，加上上一页留下的标题路径。
- 输出：若干段"（标题路径，正文）"，以及本页最后的标题路径。
- `segments = []` 准备装结果。
- `path = list(inherited_path)` 复制一份。
- 复制的目的：不直接改传进来的那一份。
- `buffer = []` 临时存正文的行。
- `def flush()` 是一个内部小函数。
- 它的活是：把 buffer 里攒的行收成一段。
- `"\n".join(buffer)` 把多行拼成一整段。
- `if body:` 有内容才加入结果。
- `segments.append(...)` 就是"往列表末尾加一个"。
- `buffer.clear()` 清空，准备攒下一段。
- `for line in text.splitlines()` 一行一行地过。
- `heading = _parse_heading(line)` 看这行是不是标题。
- 如果是标题：先 `flush()` 把上一段收尾。
- 然后 `level, title = heading` 把两个值分开拿。
- `path[: level - 1]` 意思是"只保留父级标题"。
- 加上 `[title]` 就是"父级 + 自己"。
- 例：原来是一级"员工手册"，遇到二级"考勤制度"，路径就变成两层。
- `continue` 表示这一行处理完了，直接看下一行。
- 不是标题就 `buffer.append(line)`，攒进正文。
- 循环结束后再 `flush()` 一次。
- 这一步容易忘，忘了最后一段就丢了。
- 为什么标题路径要跨页继承？
- 因为一个章节常常横跨好几页。
- 第二页开头可能没有标题，但它仍然属于上一章。

## 10. 第 110–158 行：主函数

```python
def chunk_pages(doc, chunk_size=None, chunk_overlap=None):
    size = chunk_size or settings.chunk_size
    overlap = chunk_overlap if chunk_overlap is not None else settings.chunk_overlap
    if overlap >= size:
        raise ValueError("...")
```

- 这是整个文件的主入口。
- 三个参数：文档、每块大小、重叠大小。
- 后两个默认是 `None`，意思是"没传"。
- `size = chunk_size or settings.chunk_size`：没传就用配置里的值。
- 配置里的值来自 `.env`，所以改参数不用改代码。
- 第二行写法更长。
- 原因是：`0` 也是合法数字。
- 用 `or` 会把 0 当成"没传"，所以要用 `is not None` 判断。
- `if overlap >= size` 是安全检查。
- 重叠大于等于块大小，会变成死循环式重复。
- `raise ValueError(...)` 主动报错，并写清原因。
- 好代码不藏着问题，早报错早发现。

```python
    is_markdown = doc.doc_name.lower().endswith((".md", ".markdown"))
    chunks = []
    heading_path = []

    for page in doc.pages:
        if not page.text.strip():
            continue
        if is_markdown:
            segments, heading_path = _split_markdown_segments(page.text, heading_path)
        else:
            segments = [([], page.text)]
```

- `endswith` 判断文件名结尾。
- 用来区分 Markdown 和其他格式。
- `chunks = []` 装最终的块。
- `heading_path = []` 记住当前标题路径。
- `for page in doc.pages` 一页一页处理。
- 空白的页直接跳过，不产生空块。
- Markdown 走"按标题分段"。
- 其他格式整页当一段，没有前缀。
- 这样写的好处：两种格式共用后面的切块逻辑。

```python
        for path, body in segments:
            prefix = " > ".join(path)
            budget = max(size - len(prefix) - 1, 50) if prefix else size
            splitter = _make_splitter(budget, min(overlap, budget // 2))

            for piece in splitter.split_text(body):
                piece = piece.strip()
                if not piece:
                    continue
                chunks.append(Chunk(...))
```

- `for path, body in segments` 一段一段处理。
- `" > ".join(path)` 把标题用 ` > ` 连起来。
- `budget` 是留给正文的字数。
- 算法是：总大小减去前缀长度，再减 1 个换行。
- `max(..., 50)` 保证至少留 50 字。
- `_make_splitter(...)` 造工具。
- 重叠也不能超过正文预算的一半。
- `split_text` 是真正的切块动作。
- `piece.strip()` 去掉首尾空白。
- 空的片段跳过。
- `chunks.append(Chunk(...))` 装进结果列表。
- `chunk_index=len(chunks)`：列表现在有多长，新块序号就是多少。
- 这样序号天然连续，从 0 开始。
- `text=f"{prefix}\n{piece}" if prefix else piece` 是三元表达式。
- 读法：有条件成立就用前面，否则用后面。

## 12. 回顾：数据怎么流动

```
一个文件（PDF/Word/MD）
   ↓ parse_document 解析
一堆 Page（每页有文字和页码）
   ↓ 按标题分段（仅 Markdown）
若干段（标题路径 + 正文）
   ↓ 递归切块 + 重叠
一堆 Chunk（带前缀、页码、序号）
```

- 每一层只干一件事。
- 上层不需要知道下层怎么实现。
- 这种写法叫"分层"。
- 好处：以后换解析器或换切块策略，其他层不用改。
